# C Programming Practice

This repository contains my C programming practice from the basics.

I am using this repository to learn and practice C programming concepts step by step, starting with simple programs and gradually moving towards more advanced concepts.

## Topics Covered

* Basic syntax
* Variables and data types
* Input and output
* Operators
* Conditional statements
* Loops
* Functions
* Arrays
* Strings
* Pointers
* Structures
* File handling
* Basic problem solving
